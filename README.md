# javascript-calculator-precourse

## 구현할 기능 목록

### 1. 덧셈할 문자열 입력받기
- <code>@woowacourse/mission-utils</code>의
  <code>Console.readLineAsync</code>를 사용하여 문자열을 입력받는다.
- 입력값이 빈 문자열("")이면 0을 출력한다.
- 출력 형식: `결과 : 0`



### 2. 기본 구분자 처리
- 쉼표(,)와 콜론(:)을 구분자로 사용하는 문자열을 분리하여 합산한다.
- 예시:
  - "1,2" => 3
  - "1,2:3" => 6


### 3. 커스텀 구분자 처리
- 문자열 맨 앞에 "//문자\n" 형식으로 커스텀 구분자를 지정한다.
- 예시:
  - "//;\n1;2;3" => 6
- 구현 방법:
  - 입력 문자열이 "//"로 시작하는지 확인
  - "\n" 기준으로 커스텀 구분자와 숫자 부분 분리 -> "\n" 이후 문자열부터 숫자 부분으로 처리
  - 커스텀 구분자를 기준으로 숫자 분리 후 합산


### 4. 예외 처리
- 음수 입력 시 에러 발생
- 숫자가 아닌 값 입력 시 에러 발생
- 잘못된 커스텀 구분자 형식 처리


### 5. 테스트 계획
- 커스텀 구분자 입력 테스트
- 기본 구분자 입력 테스트
- 음수 입력 예외 테스트
- 빈 문자열 입력 테스트
